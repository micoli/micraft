## 10. Crafting

### Available crafting tables

| Table | Location | Output |
|---|---|---|
| Basic workshop | Spawned in each village | Tools, common weapons |
| Forge | Village, advanced crafting | Metal weapons and armor |
| Alchemist's bench | Rare villages, dungeons | Potions, poisons, scrolls |
| Enchanting table | Village library | Equipment enchantments |
| Runic forge | Dungeons only | Epic and legendary items |

### Resources and sources

| Resource | Source | Main use |
|---|---|---|
| Wood | Generated forest | Handles, furniture, arrows |
| Stone | Underground world | Buildings, common tools |
| Iron | Underground veins | Weapons/armor level 1–3 |
| Steel | Crafted (iron + coal) | Weapons/armor level 4–6 |
| Mana crystal | Dungeons, bosses | Enchantments, wands |
| Dragon bone | Dragon boss | Legendary armor |
| Herbs | Forest, fields | Potions |
| Venom | Venomous monsters | Poisons, advanced potions |

### Recipe examples

**Iron longsword** (Forge):
- 3× Iron ingot + 1× Wooden handle
- Result: Longsword [Common] — 1d8 slashing damage

**Healing potion** (Alchemist's bench):
- 2× Life herb + 1× Empty flask + 1× Pure water
- Result: Healing potion — instantly restores 2d4+2 HP

**Sharp Enchantment I** (Enchanting table):
- Any weapon + 3× Mana crystal + 1× Griffin feather
- Result: Enchanted weapon +5% crit chance

### Crafting skill system

Each table is tied to a **skill** that progresses independently from combat level:

- `Smithing`: level 1 to 10, unlocks more complex recipes
- `Alchemy`: level 1 to 10, improves potion potency
- `Enchanting`: level 1 to 10, allows more powerful enchantments

Crafting XP is earned on each successful fabrication.
