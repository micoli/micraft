## Agent Brief

**Category:** enhancement
**Summary:** Replace `GameLoop`'s ~114-parameter constructor with `GameLoop(defaultWorld: GameWorld, <process-level
deps>)`, and migrate the tests that construct `GameLoop` onto one test helper.

**Current behavior:**
`GameLoop` takes every per-World subsystem as a constructor parameter with a default value. About 15 test files
construct it, relying on those defaults, which is how tests and production drifted apart.

**Desired behavior:**
- `GameLoop` receives the already built default `GameWorld` plus process-level dependencies only: auth provider,
  token store, RBAC and config reload hooks, chunk config, `SharedGameServices`, the E2E switch. It holds no
  per-World subsystem field of its own and reaches subsystems through a `GameWorld`.
- `Application` builds the default World with `buildGameWorld` and hands it to `GameLoop`.
- One test helper (for example `testGameLoop(world = buildGameWorld(...), …)`) is the only way tests build a
  `GameLoop`. The tests that used constructor defaults go through it.

**Key interfaces:**
- `GameLoop` constructor: process-level only
- The test helper: sensible defaults, overrides for the few process-level deps a test cares about (auth, token
  store)

**Acceptance criteria:**
- [ ] `GameLoop`'s constructor has no parameter whose type is a per-World subsystem
- [ ] No test calls the `GameLoop` constructor directly except the helper
- [ ] `make dc CMD="./gradlew :server:test"` green, `make e2e` green, `make dev-restart-server` boots without ERROR

**Out of scope:**
- Splitting `GameLoop`'s connection handling or message dispatch further
- `CommandContext` shape ([10](10-command-context-deps.md))
